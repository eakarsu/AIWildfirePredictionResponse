# Quarantined generated and demo surfaces

The previous runtime exposed generic chat-completion analysis, synthetic/sample records, mutable deletion routes, direct gap pages, and ad hoc resource/public-alert actions. Those files remain only for provenance while owners decide whether to archive or remove them; `backend/src/index.js` mounts none of them.

Only the governed boundary is supported. It consumes timestamped, versioned authoritative evidence, produces explicitly advisory forecasts and proposals, evaluates replay results, and requires independent human approval plus durable provider receipts for consequential work. It contains no provider implementation or claim that a generated recommendation is operationally safe.
